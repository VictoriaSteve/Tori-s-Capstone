# ToriesGlow API

A Django REST API for a beauty e-commerce platform.

# Features

Products (CRUD + images)
Reviews
Cart & checkout
Paystack payments
Auto stock update
Email receipts
View order details (per user)
Admin can view any order
Swagger docs

# Tech Stack

Django REST Framework
Paystack
drf-spectacular

# Endpoints

/user/
/products/
/cart/
/cart/checkout/
/cart/pay/<order_id>/
/cart/verify/<reference>/
/cart/order/<order_id>/
